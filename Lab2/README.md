# Кузнецов Егор ИТ-7, Лабораторная работа №2

## О проекте
Лабораторная работа выполнена в рамках изучения объектно-ориентированного программирования (ООП) на языке Java.
**Соблюдены все требования:**
- Решение оформлено в одном проекте, но в разных классах.
- В каждом классе присутствуют свойства (поля), конструкторы и переопределенный метод `toString()`.
- В главном классе `Main` реализован дружественный интерфейс.
- Организована проверка на корректность ввода данных с клавиатуры (защита от ввода букв вместо чисел).

## Проверка на ввод (Валидация)
В классе `Main.java` реализован дружественный интерфейс. Для предотвращения аварийного завершения программы при вводе некорректных данных (например, букв вместо цифр) используется специальный метод `readInt(Scanner sc)`.
**Как это работает:**
1. Метод использует `sc.hasNextInt()` для проверки, является ли следующий ввод целым числом.
2. Если пользователь ввел число — оно считывается и возвращается.
3. Если введен некорректный символ (буква или спецсимвол), программа выводит сообщение `"Ошибка! Введите целое число"`, очищает буфер ввода (`sc.next()`) и просит ввести значение заново.
